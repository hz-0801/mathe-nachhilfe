## Gegenprobe
Skript (Python 3, aus der Repo-Wurzel; prüft: jede Kennung genau einmal, jeder Eintrag als Datei unter `katalog/`, jede Sprosse wortgleich im Eintrag). Zeilenformat, das es erwartet: `| <kennung> | <eintrag>.md | <einheit> | <sprosse oder „keine Sprosse“> | …`.

```python
import re, sys, pathlib, collections
k = pathlib.Path("katalog/_fremd-konkordanz-nrw-zp10.md").read_text(encoding="utf-8")
zeilen = [z for z in k.splitlines() if re.match(r"\| nrw-zp10-", z)]
ids = collections.Counter(z.split("|")[1].strip() for z in zeilen)
fehler = [f"doppelt: {i}" for i, n in ids.items() if n > 1]
for z in zeilen:
    f = [s.strip() for s in z.split("|")[1:-1]]
    eintrag = pathlib.Path("katalog") / f[1].rstrip("?").strip()
    if not eintrag.is_file():
        fehler.append(f"{f[0]}: Eintrag fehlt {eintrag}"); continue
    sprosse = f[3].rstrip("?").strip()
    if sprosse != "keine Sprosse" and sprosse not in eintrag.read_text(encoding="utf-8"):
        fehler.append(f"{f[0]}: Sprosse nicht wortgleich in {eintrag}")
print(f"{len(zeilen)} Kennungen, {len(fehler)} Fehler"); print(*fehler, sep="\n")
sys.exit(1 if fehler else 0)
```
