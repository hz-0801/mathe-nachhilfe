### Lerneinheiten
1. Wurzelziehen und Lösbarkeit – reinquadratische Gleichungen x² = c und a·x² + b = 0 (x² freistellen; zwei, eine oder keine Lösung), die allgemeinere Form a·x² + b = c mit Fallbetrachtung (GYM, LISUM-PH Gymnasium Zeile 1950), Gleichungen mit quadrierter Klammer (x − d)² = c rückwärts rechnen, Lösung durch Einsetzen prüfen, Zahl der Lösungen begründen und am Graphen ablesen, Gleichung ohne Lösung angeben. (Kl. 9) ← Eingabe „wurzelziehen“, „lösbarkeit quadratische gleichung“
2. Satz vom Nullprodukt – Produktform (x − a)·(x − b) = 0 als Grundfall, Gleichungen ohne Absolutglied x² + px = 0 durch Ausklammern (GYM, LISUM-PH Gymnasium Zeile 1947; die EBR/FOR-Reihe kennt nur die fertige Produktform), Lösung durch Einsetzen bei Produktform prüfen; Produkt gleich einer Zahl ungleich null: ausmultiplizieren und ordnen (Übergang zur p-q-Formel). (Kl. 9) ← Eingabe „nullprodukt“, „ausklammern gleichung“
3. Normalform und p-q-Formel – Gleichung ordnen (alles auf eine Seite, nach Potenzen sortieren), Normieren (durch die Vorzahl von x² teilen), p und q mit Vorzeichen ablesen, Formel anwenden, Diskriminante (zwei, eine, keine Lösung), Lösungen mit Wurzel und Näherungswert, Probe, Lösungsweg wählen. (Kl. 9/10) ← Eingabe „p-q-formel“, „lösungsformel“, „quadratische gleichung lösen“

### Typen je Lerneinheit
Einheit 1: x² = c mit Quadratzahl lösen, beide Lösungen (x₁ = √c, x₂ = −√c) · x² = c ohne Quadratzahl (Wurzel stehen lassen, Näherungswert mit dem Taschenrechner) · x² = c mit negativem c: keine Lösung · x² freistellen bei a·x² + b = 0 und a·x² = b (erst umformen, dann Wurzel) · a·x² + b = c mit beliebiger rechter Seite und Fallbetrachtung (GYM) · (x − d)² = c rückwärts rechnen (zwei Fälle x − d = √c und x − d = −√c, dann d hinüberbringen) · (x − d)² = 0: genau eine Lösung · Lösung durch Einsetzen prüfen, auch negativ, (wA)/(fA) · Zahl der Lösungen an c begründen (positiv, null, negativ) · Zahl der Lösungen am Graphen ablesen (Parabel und waagerechte Gerade y = c; Nullstellen als Sonderfall c = 0) · Gleichung ohne Lösung angeben · Aussagen zu Lösungen als wahr oder falsch beurteilen (P10-Form) · Fehler finden (nur die positive Wurzel; Vorzeichen von d beim Rückwärtsrechnen; Wurzel aus einer negativen Zahl „gezogen“) · Begründen (warum x² = c mit positivem c zwei Lösungen hat; warum x² = c mit negativem c keine hat).
Einheit 2: Produktform (x − a)·(x − b) = 0, jeden Faktor null setzen · Vorzeichen in den Klammern (x + a) · gleiche Faktoren (x − a)² = 0: eine Lösung · x·(x + a) = 0 · x² + px = 0 durch Ausklammern (x = 0 oder x + p = 0) (GYM) · Minus vor dem x-Glied (GYM) · Vorzahl vor x² (a·x² + bx = 0: x ausklammern, Klammer lösen) (GYM) · Lösung durch Einsetzen prüfen bei Produktform, negativ (Klammer zuerst, Punkt vor Strich) · Produkt gleich einer Zahl ungleich null: Satz nicht anwendbar – ausmultiplizieren, ordnen, weiter mit Einheit 3 · Nullstellen einer Normalform durch Faktorisieren als Alternative zur Formel (Vorrat) · Fehler finden (durch x geteilt und Lösung null verloren; Vorzeichen beim Nullsetzen; Nullprodukt bei Produkt ungleich null) · Begründen (warum ein Produkt null ist, sobald ein Faktor null ist; warum man nicht durch x teilen darf).
Einheit 3: Normalform erkennen und p, q mit Vorzeichen ablesen · Gleichung ordnen: alles auf eine Seite, Reihenfolge x², x, Zahl · Normieren: durch die Vorzahl von x² teilen, auch bei negativer Vorzahl · p-q-Formel mit ganzzahligen Lösungen (Diskriminante Quadratzahl) · p ungerade: p halbe als Dezimalzahl · Lösungen mit Wurzel, Näherungswert runden · unter der Wurzel null: genau eine Lösung · unter der Wurzel negativ: keine Lösung · Zahl der Lösungen am Wert unter der Wurzel beurteilen (der Begriff „Diskriminante“ dafür: GYM, LISUM-PH Gymnasium Zeile 1965, Niveaustufe H) · Probe mit einer Lösung · Klammer oder Produkt zuerst auflösen (binomische Formel, x·(x + a)), dann ordnen · Gerade und Parabel gleichsetzen als Anwendung (Verfahren hier, Typ in quadratische-funktionen.md Einheit 4) · Lösungsweg wählen: Wurzelziehen, Nullprodukt oder Formel · grafische Kontrolle an der Parabel (Vorrat) · Fehler finden (ohne Normieren; Vorzeichen von −p/2; Diskriminante mit Plus; nur eine Lösung; Wurzel aufgeteilt) · Begründen (warum die Formel nur für die Normalform gilt; warum bei negativer Diskriminante keine Lösung existiert).
Einheit 4: Zahlenrätsel mit dem Quadrat einer Zahl (Wurzelziehen) · Produkt einer Zahl mit ihrem Nachfolger (Nullprodukt oder Formel) · Rechteck mit Seitenbeziehung und Fläche (Skizze, geg./ges., Gleichung, Formel) · Quadrat mit Rand (Vorrat) · Lösungen im Kontext prüfen: negative Länge ausschließen, beim Zahlenrätsel beide Zahlen zulassen · Antwortsatz mit Einheit · Fehler finden (negative Länge als Antwort; Gleichung mit Umfang statt Fläche) · Begründen (warum beim Rechteck nur eine Lösung gilt, beim Zahlenrätsel beide).

- „Zwei, eine oder keine?“ – bei x² = c nur die rechte Seite ansehen und ankreuzen: positiv, null oder negativ; nichts rechnen. Vor Einheit 1. [P10 2021-OS-K7c; Serlo 1821]
- „Steht rechts eine Null?“ – bei Produkten wie x·(x + a) = … ankreuzen, ob rechts null steht (Satz vom Nullprodukt gilt) oder eine andere Zahl (gilt nicht); nichts lösen. Vor Einheit 2. [Serlo 221145; P10 2025-OS-B1h]
- „Welche Form?“ – Gleichungen ankreuzen als reinquadratisch (kein x-Glied), Produkt gleich null, quadrierte Klammer gleich Zahl oder Normalform (x², x-Glied, Zahl, rechts null) – und daneben den Lösungsweg: Wurzelziehen, Nullprodukt, Rückwärtsrechnen, Formel. Vor Einheit 3. [LS-AA Kl. 9 II 1; Serlo 1821]
- „Was sind p und q?“ – in x² − 12x + 5 die Zahlen p = −12 und q = 5 mit Vorzeichen einkreisen und aufschreiben; nichts ausrechnen. Vor Einheit 3. [P10 2025-OS-K5c Fehlerquelle Vorzeichen von minus p halbe]
- „Ist die Vorzahl von x² eins?“ – ankreuzen, ob vor der Formel geteilt werden muss und durch welche Zahl; nichts rechnen. Vor Einheit 3. [P10 2020-OS-K3e]
- „Welche Lösung passt zur Frage?“ – zu zwei gegebenen Lösungen ankreuzen, welche als Länge oder Anzahl sinnvoll ist; nichts rechnen. Vor Einheit 4. [FD]

### Merkkasten
Einheit 1 (Wurzelziehen und Lösbarkeit):
    Wurzelziehen: x² = c hat für positives c zwei Lösungen x₁ = √c und x₂ = −√c, für c = 0 genau eine (x = 0), für negatives c keine – ein Quadrat ist nie negativ.
      x² = 36 → x₁ = 6, x₂ = −6      x² = 0 → x = 0      x² = −36 → keine Lösung
    Quadrierte Klammer: (x − d)² = c rückwärts rechnen – erst die Wurzel mit beiden Vorzeichen, dann d hinüberbringen.
      (x + 4)² = 36 → x + 4 = 6 oder x + 4 = −6 → x₁ = 2, x₂ = −10      (x + 4)² = 0 → x = −4
    Probe: Lösung einsetzen, beide Seiten ausrechnen – gleich? (wA)
    Formelsammlung: Gleichungen – quadratische Gleichungen, reinquadratische Gleichung [FS]
Quelle: [Serlo 1821, 221122] „Wurzelziehen aus einer positiven Zahl liefert zwei Lösungen, aus einer negativen keine; Scheitelform rückwärts rechnen“, sinngemäß; [P10 2021-OS-K7c] Verfahren; [LS-AA Kl. 9 II 3].

Einheit 2 (Satz vom Nullprodukt):
    Nullprodukt: Ein Produkt ist null, sobald ein Faktor null ist. Steht rechts null, jeden Faktor einzeln null setzen.
      x² − 7x = 0 → x·(x − 7) = 0 → x₁ = 0, x₂ = 7      (x + 3)·(x − 9) = 0 → x₁ = −3, x₂ = 9
    Ohne Absolutglied immer x ausklammern – nie durch x teilen, sonst geht die Lösung null verloren.
    Steht rechts nicht null, gilt der Satz nicht: ausmultiplizieren und ordnen.      x·(x + 8) = 20 → x² + 8x − 20 = 0 → Formel (Einheit 3)
    Formelsammlung: Gleichungen – quadratische Gleichungen, Satz vom Nullprodukt; Terme – Ausklammern [FS]
Quelle: [Serlo 221145, 221122] „Produktform mit dem Satz vom Nullprodukt lösen; alle Summanden auf eine Seite, x ausklammern, null ist immer eine der Lösungen“, sinngemäß; [P10 2025-OS-B1h; 2020-OS-K3e „oder Faktorisieren“]; [LS-AA Kl. 9 II 4].

Einheit 3 (Normalform und p-q-Formel):
    Normalform: x² + px + q = 0 – alles auf eine Seite, geordnet nach x², x, Zahl; die Vorzahl von x² ist eins, sonst durch sie teilen (normieren).
      3x² + 24x − 60 = 0 | : 3 → x² + 8x − 20 = 0      p = 8, q = −20
    p-q-Formel: x₁,₂ = −p/2 ± √((p/2)² − q)
      x² + 8x − 20 = 0 → x₁,₂ = −4 ± √(16 + 20) = −4 ± 6 → x₁ = 2, x₂ = −10
    Unter der Wurzel entscheidet: positiv → zwei Lösungen, null → eine Lösung, negativ → keine Lösung.
      x² + 8x + 16 = 0 → −4 ± √(16 − 16) → x = −4      x² + 8x + 20 = 0 → √(16 − 20): keine Lösung

### Typische Fehler
- Nur eine Lösung beim Wurzelziehen: x² = 49 → x = 7, die negative Lösung fehlt; ebenso bei der Formel nur die Plus-Lösung. [Serlo 221122 „beim Wurzelziehen aus einer positiven Zahl entstehen zwei Lösungen“; P10 2017-OS-K5d, 2023-OS-K4c Fehlerquelle „nur eine Lösung“]
- Vorzeichen beim Rückwärtsrechnen: (x + 8)² = 16 → x = 4 und x = 12 bestätigt statt −4 und −12. [P10 2021-OS-K7c „durch Vorzeichenfehler bestätigen“]
- „Keine Lösung“ mit „Lösung null“ verwechselt: x² = 0 als Gleichung ohne Lösung angegeben. [P10 2021-OS-K7c Fehlerquelle]
- Wurzel aus einer negativen Zahl „gezogen“: x² = −25 → x = −5 (Probe: (−5)² = 25, nicht −25). [Serlo 1821; FD]
- Durch x geteilt, Lösung null verloren: x² = 7x → x = 7. [Serlo 221145 „null ist immer eine der beiden Lösungen“; FD]
- Nullprodukt bei Produkt ungleich null: x·(x + 5) = −6 → „x = −6 oder x + 5 = −6“; die Distraktoren x = −6 und x = 3 der P10 fangen genau das ab. [P10 2025-OS-B1h Optionen; TH Wildau Brückenkurs „nur wenn das Produkt null sein soll“]
- Vorzeichen beim Einsetzen negativer Werte: für x = −2 in x·(x + 5) mit 2 · 7 = 14 statt (−2) · 3 = −6 gerechnet. [P10 2025-OS-B1h Fehlerquelle]
- Faktor null gesetzt, Vorzeichen falsch: (x + 3)·(x − 9) = 0 → x = 3 oder x = −9. [FD; Serlo 221145]
- p-q-Formel ohne Normieren: 2x² + 8x + 6 = 0 mit p = 8, q = 6. [P10 2020-OS-K3e]
- Vorzeichen von −p/2: x² − 6x + 7 = 0 mit −3 ± … statt 3 ± … gerechnet; p ohne Vorzeichen abgelesen. [P10 2025-OS-K5c; FD]
- Diskriminante mit Plus: 9 + 7 statt 9 − 7; oder Wurzel aufgeteilt: √(9 − 7) = 3 − √7. [P10 2017-OS-K5d, 2025-OS-K5c; FD]
- Gleichung nicht oder falsch geordnet: −x² − 2x + 5 = −10 mit falschem Vorzeichen von x² oder −10 umgestellt; x² + 2x − 1 = 3x + 1 → x² + x … statt x² − x − 2 = 0. [P10 2023-OS-K4c, 2021-OS-K2c, 2024-OS-K3d]
- Klammer ohne Mittelglied aufgelöst: (x − 2)² − 4 → x² − 4 − 4; (x + 3)² = x² + 9. [P10 2022-OS-K3c, 2017-OS-K5d]
- p ungerade: p halbe als ganze Zahl gerundet (x² − x − 2 = 0 mit p halbe = 1 statt 0,5). [P10 2021-OS-K2c; FD]
- Ergebnis mit Wurzel für falsch gehalten oder ohne Näherungswert gelassen; „keine Lösung“, weil die Wurzel nicht aufgeht. [P10 2025-OS-K5c; 2017-OS-K5d Bemerkung „irrational, Graph gibt nur Näherung“]
- Falscher Lösungsweg: x² = 36 mit der Formel (umständlich, Fehlerquelle) oder (x + 4)² = 36 erst ausmultipliziert; umgekehrt Wurzelziehen bei x² + 8x = 20 versucht (x-Glied übersehen). [Serlo 1821 „je nach Form leichter lösbar“; FD]
- Sachaufgabe: negative Lösung als Länge übernommen; beim Zahlenrätsel eine der beiden Zahlen weggelassen; Antwort ohne Einheit. [FD]
